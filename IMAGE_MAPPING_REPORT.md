## 🔄 Smart Matching Features

The mapping script uses intelligent matching:

1. **Exact Name Matching** - Matches product names to image filenames
2. **Brand Matching** - Uses brand names for better accuracy
3. **Keyword Extraction** - Identifies key terms (e.g., "Ketepa", "Brookside")
4. **Fuzzy Matching** - Handles variations in spelling and spacing
5. **Shared Images** - Multiple products can share the same image
   - Example: Both "Coca-Cola" and "Fanta" use the same cola drink image
   - Example: All toilet papers share similar tissue images
